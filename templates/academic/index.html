Patrón de Diseño Backend

Enmascaramiento de Endpoints DRF

En lugar de exponer la interfaz navegable nativa (Browsable API), el servidor entrega cascarones de plantillas HTML. JavaScript asíncrono intercepta las peticiones y se comunica con la API REST protegida por tokens CSRF:

1. Django render() entrega plantilla 2. fetch() solicita JSON 3. DOM renderiza dinámicamente
Probar Consumo Asíncrono Endpoint Crudo (/api/courses/)
// Petición asíncrona de ejemplo:
fetch('/api/courses/')
.then(res => res.json())
.then(data => {
// Inyecta datos en tabla HTML
});
